# Hearing-loss-simulator

## Hindi Paragraph Hearing-Loss Simulator

The root `index.html` and [`hindi-paragraph-simulator.html`](./hindi-paragraph-simulator.html) contain the Hindi-language educational interface. It compares normal, mild, moderate, and severe illustrative profiles, supports recording/uploading speech audio, simple browser-based filtering, and a visual masked-word display.

## Publish online with GitHub Pages

1. Open **Settings → Pages** for this repository: https://github.com/noorain04-web/Hearing-loss-simulator/settings/pages
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the deployment to finish. The site URL should be https://noorain04-web.github.io/Hearing-loss-simulator/ . If the repository is private and GitHub does not allow Pages for its current plan, change repository visibility to Public only if you are comfortable making its contents public, or use a plan that supports Pages for private repositories.

**Important:** This is an educational demonstration, not a clinically validated hearing-loss model or diagnostic tool. The filters are simplified and do not represent a specific audiogram or reproduce each person's experience. Use a safe listening volume. Audio is processed locally in the browser.
